# 🌤️ Weather App

A sleek and responsive weather forecasting web app built with **React**, styled using **Tailwind CSS**, and powered by **Axios** and the **Weather API**. This app allows users to search for any city and view detailed weather information including temperature, humidity, wind speed, sunrise/sunset, and forecasts — all with a day/night themed background.

---

## 🚀 Features

- 🔍 **City Search:** Look up real-time weather data by any location
- 🌤️ **Current Weather Display:** View temperature, conditions, and key metrics
- 🌡️ **Current Conditions:** Temperature in Celsius/Fahrenheit, weather descriptions, wind speed, and humidity
- 🌍 **City Management:** Add and remove your favorite cities
- 📱 **Fully Responsive:** Works on mobile, tablet, and desktop
- 📆 **Hourly & Daily Forecasts:** View weather predictions for the next hours and upcoming days
- 🌅 **Sunrise & Sunset:** Displays exact times for sunrise and sunset
- 📈 **High/Low Temperature:** Highlights daily high and low temperatures
- 🌙 **Dynamic Backgrounds:** Changes theme automatically for day and night ,rain/snow/stromy/  clear/clouds conditions

---

## 🛠️ Tech Stack

- **React.js** – Frontend JavaScript library
- **Tailwind CSS** – Utility-first CSS framework
- **Axios** – For making HTTP requests to the Weather API
- **Weather API** – Real-time weather data provider

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MrsRafiaShahid/weather.git
   cd weather-app
   ```
2. **Install dependencies:**

```bash
npm install
```
3. **Create .env file in the root directory and add your API key:**

```
env
VITE_WEATHER_API_KEY=your_api_key_here
```
4. **Start the development server:**

```bash
npm run dev
```
